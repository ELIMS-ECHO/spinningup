## 1. 决策链：谁负责选择，谁负责反馈？

考虑一台会在任务中移动的机器人。它必须在“快走”和“稳走”之间选择。快走可能立即节约时间，也可能发生意外，让后面的代价变大。

这不是一个只求当前分类准确率的问题。机器人的动作会影响后面的局面，而后面的局面又影响未来能得到什么奖励。

我们用如下时间链描述它：

```text
时刻 t：
环境内部状态 s_t
    ↓ 产生可观测信息
智能体接收 o_t
    ↓ 根据策略 π 选动作
动作 a_t
    ↓ 与环境发生交互
转移到 s_(t+1)，并产生奖励 r_t
    ↓
进入下一轮
```

- **环境（environment）**：被交互的世界及其变化规律。
- **智能体（agent）**：选择动作的决策者。
- **状态 \(s_t\)**：用来描述环境在时刻 \(t\) 的内部状况。
- **观测 \(o_t\)**：智能体实际获得的信息。
- **动作 \(a_t\)**：智能体可以执行的选择。
- **奖励 \(r_t\)**：对当前结果提供数值反馈的信号。

注意：奖励**不是**自动等同于“人类真正关心的最终目标”。奖励函数如果设计得不好，智能体仍可能学会最大化分数，却制造不想要的实际结果。这是建模问题，不是优化器自行解决的问题。

### 检查点 A

问：如果决策者能看到机器当前速度，但看不到设备内部磨损程度，“速度”属于状态还是观测？

答：在这个例子里，速度是可获得的观测信息；磨损也属于环境真实状况的一部分，但可能没有包含在观测中。状态与观测不是永远互斥的两组变量：一个观测可以只是状态的一部分。

## 2. 状态不等于观测

假设环境真实情况为：

\[
s_t=(\text{位置},\text{速度},\text{设备健康程度})
\]

传感器只能报告：

\[
o_t=(\text{位置},\text{速度})
\]

因此，策略在实际运行中未必能直接使用完整的 \(s_t\)。它只能根据 \(o_t\) 或一段观测历史来作出决策。

为了简洁，很多强化学习教材将策略写为 \(\pi(a\mid s)\)，但这常隐含了完整可观测的前提。部分可观测情形需要格外注意此处的区别。

**你需要形成的判断**：给模型更多文字，不自动等于提供了更好的状态信息。关键是这些输入是否包含有助于区分行动优劣的信息，并且是否真实可得。

## 3. 策略是什么：确定性规则与随机性规则

策略（policy）规定了智能体在某种输入下怎样选动作。

**确定性策略：**

\[
a_t=\mu(s_t)
\]

同一状态下给出一个指定的动作。

**随机性策略：**

\[
a_t\sim\pi(\cdot\mid s_t)
\]

这里 \(\pi(a\mid s)\) 表示在状态 \(s\) 下选动作 \(a\) 的概率。它不是“动作一定正确的概率”。

例如，“快走”概率 0.2，“稳走”概率 0.8，就是一个合法的随机策略。若以后使用神经网络表达这些概率，就会出现带参数的策略 \(\pi_\theta\)。但**神经网络不是 RL 的定义**，它只是可能采用的一种函数表示工具。

动作也有两类常见形式：

- 离散动作：从“快走/稳走”等有限选项中选一个。
- 连续动作：输出一个实数或实数向量，例如速度或转矩。

这会影响适用的算法与策略输出层。

## 4. 为什么要区分奖励与回报

一个动作的当前奖励高，不意味着长远更好。

令 \(r_t\) 是第 \(t\) 步的奖励。两种常见回报定义为：

**有限时域、不折扣：**

\[
G_0=\sum_{t=0}^{T}r_t
\]

**无限时域、折扣回报：**

\[
G_0=\sum_{t=0}^{\infty}\gamma^t r_t,\qquad 0<\gamma<1
\]

其中 \(\gamma\) 称为折扣因子。它控制未来奖励相对当前奖励的权重，也使某些条件下的无限级数更容易在数学上处理。

不要把“\(\gamma\) 越大就是越有远见”当作所有任务中都正确的价值判断。它只是具体数学目标的一个参数。改变它可能改变最优策略。

## 5. 一个可以手工算完的随机决策问题

**以下完全是本讲义新设计的例题。** 假设机器人在起点只需选择一次动作，随后环境给出一个延迟奖励，任务结束。

采取折扣回报：

\[
G=r_0+0.9r_1
\]

行动及结果如下：

| 选择 | 立即奖励 \(r_0\) | 下一步奖励 \(r_1\) |
| --- | ---: | --- |
| 快走 F | +3 | 50% 概率为 -8；50% 概率为 +2 |
| 稳走 S | +1 | 恒为 +1 |

### 先算“快走”

延迟奖励的期望：

\[
\mathbb E[r_1\mid F]=0.5(-8)+0.5(2)=-3
\]

因此：

\[
\mathbb E[G\mid F]=3+0.9(-3)=\boxed{0.3}
\]

### 再算“稳走”

\[
\mathbb E[G\mid S]=1+0.9(1)=\boxed{1.9}
\]

所以当前这套奖励和折扣设定下，“稳走”的**期望回报**更高，即使它立即获得的奖励更低。

注意：\(0.3\) 不是每次快走的实际得分。快走实际会得到 \(-4.2\) 或 \(4.8\)；\(0.3\) 是多次随机重复试验的期望。

## 6. 从单个动作走到策略价值

现在规定随机策略 \(\pi\)：

\[
\pi(S\mid s_0)=0.8,\qquad \pi(F\mid s_0)=0.2
\]

**状态价值 \(V^\pi(s)\)**：从状态 \(s\) 开始，按策略 \(\pi\) 行动的期望回报。

**动作价值 \(Q^\pi(s,a)\)**：从状态 \(s\) 开始，先执行指定动作 \(a\)，随后按 \(\pi\) 行动的期望回报。

这个例子只有一次主动决策，所以：

\[
Q^\pi(s_0,F)=0.3,\qquad Q^\pi(s_0,S)=1.9
\]

在起点按策略混合动作：

\[
\begin{aligned}
V^\pi(s_0)
&=\sum_a\pi(a\mid s_0)Q^\pi(s_0,a)\\
&=0.2(0.3)+0.8(1.9)\\
&=\boxed{1.58}
\end{aligned}
\]

这个结果同时说明一个关键关系：

\[
V^\pi(s)=\mathbb E_{a\sim\pi(\cdot\mid s)}[Q^\pi(s,a)]
\]

**什么时候不可以简单用 0.3 和 1.9 当作任何策略的 Q 值？** 当动作之后还存在新的决策，且后续策略会影响结果时。这里之所以可以，是因为起点之后没有其他主动选择。

## 7. RL 最终优化的是策略的期望回报

令 \(\tau=(s_0,a_0,s_1,a_1,\dots)\) 表示轨迹（trajectory）。当策略和环境都含随机性时，即使初始状态一样，也可能发生不同轨迹。

记 \(P(\tau\mid\pi)\) 为策略 \(\pi\) 下出现一条轨迹的概率，则策略的目标为：

\[
J(\pi)=\mathbb E_{\tau\sim\pi}[G(\tau)]
\]

而优化问题是：

\[
\pi^*=\arg\max_{\pi}J(\pi)
\]

在本例中，如果不附加其他风险约束，且只能在 F、S 中选动作，则最优策略是始终选 S，其起点价值为 \(1.9\)。

严格区分：

- \(r_t\) 是一次反馈。
- \(G(\tau)\) 是整条轨迹的回报。
- \(J(\pi)\) 是策略在所有可能轨迹上的期望表现。
- \(V^\pi(s)\) 是在特定起点状态下，给定策略的期望回报。
- \(Q^\pi(s,a)\) 是在特定起点强制先选一个动作，再依策略行动的期望回报。

这五者不是五种近义词。

## 8. 不依赖神经网络的最小实验

保存为 `lesson01_monte_carlo.py`，直接用 Python 运行，无需安装 PyTorch：

```python
import random

rng = random.Random(2026)
N = 20_000
GAMMA = 0.9

def episode(action):
    if action == "F":
        delayed = -8 if rng.random() < 0.5 else 2
        return 3 + GAMMA * delayed
    if action == "S":
        return 1 + GAMMA * 1
    raise ValueError("unknown action")

def sample_mean(values):
    return sum(values) / len(values)

f_return = sample_mean([episode("F") for _ in range(N)])
s_return = sample_mean([episode("S") for _ in range(N)])

policy_returns = []
for _ in range(N):
    action = "S" if rng.random() < 0.8 else "F"
    policy_returns.append(episode(action))

print("快走 Monte Carlo:", round(f_return, 3), "理论值: 0.3")
print("稳走 Monte Carlo:", round(s_return, 3), "理论值: 1.9")
print("混合策略 Monte Carlo:", round(sample_mean(policy_returns), 3), "理论值: 1.58")
```

**实验前预测**：三个采样均值应分别接近 0.3、1.9、1.58；快走与混合策略的估计不会每次恰好等于理论值，因为样本随机。

**实验记录**：本代码目前为教学草稿，尚未在最终发行环境中验证。正式教材应记录实测输出、Python 版本、代码提交号及验证结论，不能将“预计输出”冒充运行证据。

### 错误排查

如果“快走”的平均值大于 1.9，不要立即断言手算错误。先检查样本量、延迟奖励符号、折扣计算、抽样代码和随机性；再增加样本量比较结果。极少样本可能得到偏离期望的均值。

## 9. 自测：理解到什么程度才算学会？

**题 1**：为什么 \(\pi(F\mid s)=0.2\) 不能解释成“快走成功率是 20%”？

**题 2**：在例题中，为什么 \(Q^\pi(s_0,F)=0.3\) 与 \(\pi(F\mid s_0)\) 选多大没有关系？

**题 3**：把折扣因子改成 \(\gamma=0.5\)，哪个动作期望回报更高？请手算。

**题 4**：如果把折扣因子进一步改为 \(\gamma=0.1\)，动作排名会不会改变？说明原因。

**题 5**：为什么不能凭“训练后累计回报提升”就断言新策略现实中更安全？

### 答案与判定依据

1. \(\pi(F\mid s)\) 是策略作出某个动作的概率；动作成功率属于环境在该动作之后产生结果的条件概率，两者概念不同。
2. 因为只在起点做一次选择，固定了起点动作后，后续没有可由 \(\pi\) 控制的动作，因此混合概率不影响这个动作的条件期望。
3. 快走：\(3+0.5(-3)=1.5\)；稳走：\(1+0.5(1)=1.5\)，两者相同。
4. 快走：\(3+0.1(-3)=2.7\)；稳走：\(1+0.1=1.1\)。改变折扣后，快走的期望回报更高。此时不能只依据 \(\gamma=0.9\) 时的结论来选动作。
5. 因为回报只评价所定义的目标；环境与奖励函数可能没有把安全代价完整计入。还需看失败概率、约束满足情况和环境覆盖率。

## 10. 本章的边界

此处真正掌握的是**强化学习的问题表示与评价目标**，还没学习“如何根据经验更新策略”。策略梯度、价值函数估计、神经网络训练、PPO 等算法都在后面的章节。
