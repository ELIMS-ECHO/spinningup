# 中文学习版：编写规约与目录（工作稿）

> 状态：试编第 1 章。不是完成版教材，不是 OpenAI 官方译本。

## 目标

将公开资料整理为**可自学、可验证、能真正获得技术理解**的中文深度强化学习学习资料。读者应能独立解释关键定义、推导基础公式、完成最小实验、识别算法的适用条件与失败模式，而非只记住术语。

## 原文边界与准确性控制

1. 以仓库中实际文件为依据。每篇讲义的编辑记录注明原文文件、相应小节及核查情况。
2. 清楚区分：**原资料讲解的知识**、**编者额外设计的教学例子**、**后续补充的现代工程实践**；不得将新增加的例题或解释冒充官方原文。
3. 所有公式保留变量定义、适用前提、推导及可以复算的数值例子。不能只写公式与通俗比喻。
4. 每节至少包括：学习目标 → 必要定义 → 机制或推导 → 可核对实例 → 常见误解 → 自测题（含答案）。
5. 算法部分必须包括：输入输出、优化目标、更新式、伪代码、最小可运行实现、实验记录、适用条件和已知失败模式。
6. 旧软件依赖不直接当作当前安装指南；后续运行实验时需记录 Python/库版本、随机种子和运行命令。
7. 外部链接、视频、论文图像不因被网页嵌入就自动获得再许可；出版前做第三方资产核查。优先重绘自己的图。

## 教材结构（拟定，不代表原资料现有目录）

- 第一编 决策基础：智能体、环境、状态与观测、动作、策略、轨迹、奖励与回报、价值函数、MDP
- 第二编 从决策问题到学习算法：Bellman 关系、采样、探索、蒙特卡洛与时序差分、函数逼近和梯度
- 第三编 策略优化：VPG、TRPO、PPO
- 第四编 基于价值与演员-评论家：DDPG、TD3、SAC
- 第五编 复现实验：训练曲线、随机种子、评价指标、失败实验和实现细节
- 第六编 专题拓展：哪些环境适合 RL，哪些适合固定策略、组合优化或 LLM 高层选择

**说明**：第二编和第六编中的部分内容需要由编者自主补充，不得伪称直接来自 Spinning Up。
