==================================
深度确定性策略梯度（DDPG）
==================================

.. contents:: 目录

背景
==========

（前置内容：`强化学习导论第一部分：最优 Q 函数与最优动作`_）

.. _`强化学习导论第一部分：最优 Q 函数与最优动作`: ../spinningup/rl_intro.html#the-optimal-q-function-and-the-optimal-action

深度确定性策略梯度（DDPG）是一种同时学习 Q 函数和策略的算法。它利用离策略数据和贝尔曼方程学习 Q 函数，再利用 Q 函数学习策略。

这一方法与 Q-learning 密切相关，出发点也相同：如果已知最优动作价值函数 :math:`Q^*(s,a)`，那么在任意给定状态下，都可以通过求解下式找到最优动作 :math:`a^*(s)`：

.. math::

    a^*(s) = \arg \max_a Q^*(s,a).

DDPG 交替学习 :math:`Q^*(s,a)` 和 :math:`a^*(s)` 的近似函数，并专门针对连续动作空间设计。这里的“专门针对连续动作空间”究竟意味着什么？关键在于如何计算 :math:`\max_a Q^*(s,a)` 中对动作的最大化。

当离散动作的数量有限时，求最大值并不困难：只需分别计算每个动作的 Q 值并直接比较。（这样也就得到了最大化 Q 值的动作。）但在连续动作空间中，我们无法穷举所有动作，求解这一优化问题也并非易事。若使用普通优化算法，计算 :math:`\max_a Q^*(s,a)` 就会成为成本高昂的子程序；而智能体每次与环境交互、需要选择动作时都必须运行它，这无法接受。

由于动作空间是连续的，我们假设 :math:`Q^*(s,a)` 关于动作参数可微。于是可以利用这一性质，为策略 :math:`\mu(s)` 构造高效的、基于梯度的学习规则。这样，每当需要计算 :math:`\max_a Q(s,a)` 时，就不必运行昂贵的优化子程序，而可以使用近似 :math:`\max_a Q(s,a)\approx Q(s,\mu(s))`。详见“关键公式”。

基本信息
-----------

* DDPG 是离策略（off-policy）算法。
* DDPG 只能用于连续动作空间环境。
* DDPG 可以理解为连续动作空间中的深度 Q-learning。
* Spinning Up 的 DDPG 实现不支持并行化。

关键公式
-------------

下面解释 DDPG 的两个部分：学习 Q 函数，以及学习策略。

DDPG 的 Q-learning 部分
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

首先回顾描述最优动作价值函数 :math:`Q^*(s,a)` 的贝尔曼方程：

.. math::

    Q^*(s,a) = \underset{s' \sim P}{{\mathrm E}}\left[r(s,a) + \gamma \max_{a'} Q^*(s', a')\right]

其中 :math:`s'\sim P` 是简写，表示环境从分布 :math:`P(\cdot|s,a)` 中采样下一状态 :math:`s'`。

这个贝尔曼方程是学习 :math:`Q^*(s,a)` 近似函数的起点。假设近似函数是参数为 :math:`\phi` 的神经网络 :math:`Q_\phi(s,a)`，并且已经收集了转移数据集 :math:`\mathcal D`，其中每个转移为 :math:`(s,a,r,s',d)`，:math:`d` 表示 :math:`s'` 是否为终止状态。可以定义**均方贝尔曼误差（MSBE）**，大致衡量 :math:`Q_\phi` 满足贝尔曼方程的程度：

.. math::

    L(\phi, {\mathcal D}) = \underset{(s,a,r,s',d) \sim {\mathcal D}}{{\mathrm E}}\left[
        \Bigg( Q_{\phi}(s,a) - \left(r + \gamma (1 - d) \max_{a'} Q_{\phi}(s',a') \right) \Bigg)^2
        \right]

这里计算 :math:`(1-d)` 时，使用了 Python 的约定：True 视为 1，False 视为 0。因此当 d==True，即 :math:`s'` 为终止状态时，Q 函数应反映智能体在当前转移之后不会获得额外奖励。（这一记号也与后面的代码实现一致。）

使用函数近似的 Q-learning 算法，包括 DQN 及其各种变体和 DDPG，很大程度上都基于最小化这一 MSBE 损失。它们共同使用两项值得说明的技巧；随后再介绍 DDPG 特有的细节。

**技巧一：经验回放缓冲区。** 所有使用深度神经网络近似 :math:`Q^*(s,a)` 的标准算法都会使用经验回放缓冲区，即保存先前经验的集合 :math:`\mathcal D`。为了使算法运行稳定，缓冲区应足够大，容纳多种经验，但保留所有历史数据也未必总是有益。如果只使用最新的数据，就会对其过拟合，导致训练出问题；如果使用过多经验，又可能降低学习速度。实际使用时可能需要调参。

.. admonition:: 你应该知道

    我们提到 DDPG 是离策略算法，现在正好解释为什么以及如何做到这一点。注意，回放缓冲区*应该*包含旧经验，即使这些经验由已经过时的策略产生。为什么仍然能够使用它们？因为贝尔曼方程*不关心*使用哪些转移元组、动作如何选择，也不关心某次转移之后发生什么。最优 Q 函数应当对*所有*可能的转移都满足贝尔曼方程。因此，曾经经历过的任何转移，都可以用于通过最小化 MSBE 拟合 Q 函数近似器。

**技巧二：目标网络。** Q-learning 算法使用**目标网络**。下式：

.. math::

    r + \gamma (1 - d) \max_{a'} Q_{\phi}(s',a')

称为**目标值（target）**，因为最小化 MSBE 时，我们希望 Q 函数的输出接近这个目标值。问题在于目标值也依赖正在训练的同一组参数 :math:`\phi`，这使 MSBE 的最小化过程不稳定。解决办法是使用一组与 :math:`\phi` 接近但更新滞后的参数，也就是第二个网络：目标网络。其参数记作 :math:`\phi_{\text{targ}}`。

在基于 DQN 的算法中，目标网络每隔固定步数直接复制主网络的参数。在 DDPG 一类算法中，目标网络在主网络每次更新后，使用 Polyak 平均进行一次更新：

.. math::

    \phi_{\text{targ}} \leftarrow \rho \phi_{\text{targ}} + (1 - \rho) \phi,

其中 :math:`\rho` 是介于 0 与 1 之间、通常接近 1 的超参数。（代码中称为 polyak。）

**DDPG 特有的细节：计算目标值中对动作的最大化。** 如前所述，在连续动作空间中，计算目标值里的动作最大值十分困难。DDPG 使用**目标策略网络**计算一个近似最大化 :math:`Q_{\phi_{\text{targ}}}` 的动作。目标策略网络的获得方式与目标 Q 函数相同：在训练过程中对策略参数进行 Polyak 平均。

综合上述内容，DDPG 的 Q-learning 部分通过随机梯度下降，最小化以下 MSBE 损失：

.. math::

    L(\phi, {\mathcal D}) = \underset{(s,a,r,s',d) \sim {\mathcal D}}{{\mathrm E}}\left[
        \Bigg( Q_{\phi}(s,a) - \left(r + \gamma (1 - d) Q_{\phi_{\text{targ}}}(s', \mu_{\theta_{\text{targ}}}(s')) \right) \Bigg)^2
        \right],

其中 :math:`\mu_{\theta_{\text{targ}}}` 是目标策略。

DDPG 的策略学习部分
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

DDPG 的策略学习相当简单。我们希望学习一个确定性策略 :math:`\mu_\theta(s)`，使其给出最大化 :math:`Q_\phi(s,a)` 的动作。由于动作空间连续，并且假设 Q 函数关于动作可微，因此只需针对策略参数执行梯度上升，求解：

.. math::

    \max_{\theta} \underset{s \sim {\mathcal D}}{{\mathrm E}}\left[ Q_{\phi}(s, \mu_{\theta}(s)) \right].

注意，这里将 Q 函数的参数视为常量。
