## 教材包含什么？

- **强化学习基础**：核心概念、数学表述及学习路径。
- **经典算法**：VPG、TRPO、PPO、DDPG、TD3、SAC。
- **实验工具**：运行实验、保存与加载、绘图、日志和相关工具说明。
- **研究资源**：重要论文、练习与基准说明。

当前收录 **24 篇中文教材**。这是一套学习与阅读资源，不是新的强化学习算法实现，也不宣称覆盖原站全部页面。

## 两种阅读方式

### 方式一：直接在 GitHub 在线阅读

打开 **[中文教材完整目录](https://github.com/ELIMS-ECHO/spinningup/blob/learning-edition-zh/online/README.md)**，按章节阅读，无需安装 Obsidian。

### 方式二：下载 Obsidian 学习库

1. 从 **[GitHub Releases v1.0.0](https://github.com/ELIMS-ECHO/spinningup/releases/tag/v1.0.0)** 下载 ZIP。
2. 解压后，在 Obsidian 中打开 `SpinningUp-Obsidian-Vault` 文件夹。
3. 从 `00_课程导航.md` 开始阅读。

ZIP 包含中文 Markdown 教材、图片、原始 RST 备份、目录和导入说明；**不包含私人学习笔记**。同时提供 [SHA-256 校验文件](https://github.com/ELIMS-ECHO/spinningup/releases/download/v1.0.0/SHA256SUMS.txt)。
