# Spinning Up 深度强化学习中文学习版

基于 [OpenAI Spinning Up](https://github.com/openai/spinningup) 的中文学习资源。提供已提交的 24 篇中文教材的 GitHub Markdown 在线阅读版。

## 在线阅读

无需安装 Obsidian。点击以下章节即可在 GitHub 阅读自动生成的 Markdown；[完整目录](online/README.md)，也可查阅 `docs/` 下的中文 RST 源文件。

## 离线版

仓库中的 `scripts/export_obsidian.py` 可将已提交的 24 篇中文 RST 转换成 Obsidian Vault；自动构建下载属于临时 Actions 附件，不是长期发布版。正式 Release 尚未发布，请勿将其宣传为已有下载。

## 隐私与收录范围

本公开仓库只承载已经提交的教材源文件和导出工具，不收录本地个人学习笔记。转换脚本生成的空白笔记模板不等于任何用户的真实笔记。
